# Dockerized Node.js Web Application

A simple Node.js web application built with Express and containerized using Docker.

## 🚀 Project Overview

This project demonstrates how to:

- Build a Node.js web application using Express
- Create a Dockerfile
- Build a Docker image
- Run the application inside a Docker container
- Map Docker container ports to the host machine
- Manage the project using Git and GitHub

## 🛠️ Technologies Used

- Node.js
- Express.js
- Docker
- Git
- GitHub
